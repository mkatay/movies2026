# Movies projekt

- React Router – többoldalas alkalmazás, útvonalak kezelése.



- Újrafelhasználható komponensek – például egyetlen MovieCard a filmekhez és sorozatokhoz.



- Axios – külön API-modulban történő adatlekérés.



- async/await – aszinkron függvények.



- useEffect, useState – adatok betöltése és tárolása.



- Dinamikus útvonalak – például egy film részletező oldala.



- Keresés – a TMDB keresési végpontjainak használata.
